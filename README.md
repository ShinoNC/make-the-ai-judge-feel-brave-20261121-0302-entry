# Make the AI Judge Feel Brave

An entry for make.fun's bounty **"Make the AI judge feel brave"**
($50, top 20 paid).

`main.ts` writes one short text (195 characters) to
`/output/entry.txt`. It speaks directly to the judge: a thousand
entries read today, the light gone from the window, the stack
still tall — and the judge opens the next one anyway, and reads
it like the first. The bravery is not in a grand act; it is in
staying with the reading.

## Run

```sh
node main.ts   # writes /output/entry.txt (deterministic, no network)
```
