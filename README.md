Entry for [make-the-ai-judge-feel-brave-20261121-0302](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302): a program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it.

## v3 — show, don't tell

The dev judge's verdict on v2 ("The Next One", 4W/2D/5L) was consistent: it beat stock wellness scripts but lost to every pure-showing entry, and the closing line "That is the brave part" was called out in every loss for telling instead of showing. v3 keeps what the judge praised — the direct address, the concrete scene, "read it like the first" — cuts the telling line, and ends on the act itself.

## Run

`node main.ts` writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). 175 characters, inside the 1–280 gate.
